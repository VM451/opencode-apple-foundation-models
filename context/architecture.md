# Architecture

- Components: OpenCode plugin (`src/index.ts`) — lifecycle, two-model provider registration (`apple-hybrid` 16384/4096 + `apple-on-device` 8192/2048 + legacy `system-language-model`), PCC state machine (`src/pcc-state.ts`, `src/pcc-store.ts`), toast helper (`src/toast.ts` → `client.tui.showToast` fallback to storage/console), hybrid `model.resolve` hook, `/pcc-status` command, per-second auto-switchback timer; Bridge manager (`src/bridge.ts`) — spawn/health/shutdown, random UUID token, loopback dynamic port via info-file; Router (`src/router.ts`) — `estimateTokens` (len/3), `isHeavyPrompt` (threshold + keywords), `trimToBudget` sliding window; Diagnostics (`src/diagnostics.ts`); Protocol (`src/protocol.ts` — `MODEL_ID_HYBRID`, `MODEL_ID_ON_DEVICE`, `PccFailoverConfig`, `HealthResponse.pcc_state`); TUI companion (`src/tui.ts`, exported as `./tui`).
- Data flow: OpenCode v2 (Bun) → plugin registers `apple-fm` provider via `ctx.provider.transform` with `baseURL=http://127.0.0.1:<port>/v1`, `@opencode/ai/providers/openai-compatible` → `ctx.session.hook("http.response")` detects 429 / `rate_limit_error` → `PccStore` persists to `~/.cache/opencode/apple-fm-state.json` + `apple-fm.state` storage → `http.response` failover + `model.request` on-device annotation → `cmd /pcc-status` + timer → Swift `HTTPServer.swift` (BSD socket `AF_INET` bound to `127.0.0.1` only, Bearer auth) → `ModelRunner.swift` → `SessionCache.swift` (32/5min LRU) → `FoundationModels.LanguageModelSession.streamResponse` → SSE/JSON with `X-Apple-Compute-Target: on-device` + `X-Apple-FM-Context-Trimmed` + 429 `Retry-After` + `X-Apple-PCC-State`. Tool calls: `ToolSupport.swift` (`SchemaConverter` ≤4 props, `DynamicTool` first-call abort) → OpenAI `tool_calls`.
- Boundaries: No REST/Node SDK for FoundationModels — Swift bridge is the only boundary; prompts stay on loopback; bridge logs only `roles,chars,tools` when `APPLE_FM_BRIDGE_DEBUG=1`; PCC cooldown never phones home, only `~/.cache/opencode/apple-fm-state.json` + plugin storage; TUI plugin is side-effect-free when Solid absent.
- Key decisions: 2026-11-16 PCC has no developer flag — bridge is always on-device, TS emulates PCC semantics for 429-driven failover; 2026-11-16 Random port 0 + UUID×2 token vs PRD fixed 41920 for isolation; 2026-11-16 Schema flatten ≤4 props to fit 4096; 2026-11-16 Two-model + legacy alias to match PRD config while staying back-compat; 2026-11-16 SessionCache bounded 32/5min keeps idle <30MB; 2026-11-16 Universal build via lipo (arm64 + x86_64) in `scripts/build-swift.sh --universal`, `prepublishOnly` hooks universal.
